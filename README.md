# greenden-tailwind

Greenden - Plant Store Website
Greenden is a responsive plant store website built using HTML, Tailwind CSS, and JavaScript.
The project showcases a clean UI design with responsive navigation, a product display grid, and a dynamic product search feature.

# Features

- Responsive navigation bar
- Mobile sidebar menu with open and close functionality
- Product search functionality on the products page
- Responsive product grid layout
- Styled using Tailwind CSS
- Smooth hover effects and transitions

# Technologies Used

HTML5 – Structure of the website
Tailwind CSS – Styling and responsive layout
JavaScript – Interactive features like sidebar toggle and product search

# Pages Included

Home Page
- Hero section
- Featured plants
- Navigation menu

Products Page
- Product grid layout
- Search functionality to filter plants

Contact Page
- Simple contact form layout

# Functionalities Implemented
Sidebar Navigation
- Mobile responsive menu
- Opens when clicking the menu icon
- Closes when clicking the close button

Product Search
- Users can search plants by name
- Products dynamically filter based on input
- Implemented using JavaScript DOM manipulation
