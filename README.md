# greenden-tailwind

Greenden is a responsive plant-themed website built using HTML and Tailwind CSS.
This project was created to strengthen practical skills in utility-first styling, responsive layouts, and modern UI structure using Tailwind.
The website includes a Home page, Products page, and Contact page designed with a clean and nature-inspired interface.

# Live Features

- Fully responsive design (mobile, tablet, desktop)
- Utility-first styling using Tailwind CSS
- Modern UI layout with grid & flexbox
- Sticky navigation bar
- Product showcase section
- Clean component-based structure
- Beginner-friendly project structure

# Purpose of the Project

-This project was built as a hands-on practice to:
     - Understand Tailwind CSS utility classes
     - Build responsive layouts without custom CSS
     - Practice Flexbox and Grid systems
     - Learn component structuring in HTML
     - Improve UI alignment and spacing techniques
     - Develop real-world frontend project experience
